# 定制模板使用说明（占位文档）

**当前状态：尚未配置实际模板文件。** 下面是模板就绪后的存放和调用规则。

## 用户尚未提供模板文件时怎么办

不要假设用户有模板，也不要主动追问打断访谈节奏。按无模板默认流程走。只有当用户主动提到"用我的模板"但没提供文件时，提醒一句："没看到模板文件，上传一下还是先用默认样式？"

## 模板就绪后的存放规则

- 如果只有一套通用模板，放在 `assets/templates/default.pptx`
- 如果对外、对内分别有不同模板，分别放在：
  - `assets/templates/external.pptx`（对外提案/客户演示用）
  - `assets/templates/internal.pptx`（内部汇报用）
- 文件命名保持语义清晰，避免用 v1/v2/final 这类无法一眼判断用途的命名

## 与阶段2"选档位"的配合

阶段2 Step 1 确认档位（对外/对内）后，如果对应的模板文件已存在于 `assets/templates/`，直接使用该模板文件路径传给 pptx skill，让其走"基于模板编辑"的路径（读取模板已有版式、配色、字体，将大纲内容套入，而非自由设计新样式）。

如果只有一套通用模板但用户要求区分对外/对内的设计精度，模板本身的版式/配色保持不变，靠内容密度（每页信息量）和文字语气的调整来体现档位差异，不要在没有模板支持的情况下让AI自由发挥配色和排版——这会破坏"复用模板、风格统一"的初衷。

## 多次使用时的复用方式

提醒用户：若希望以后调用本skill时不用每次重新上传模板文件，可以将模板文件放入 Claude 项目（Projects）的知识库中，这样同一项目内的后续对话能直接访问，无需每次手动上传。具体说明详见与用户的历史沟通，本文档仅记录技术侧的存放与调用规则。
